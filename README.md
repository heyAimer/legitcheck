This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

Set up :
- npx create-next-app@latest
- npm install scss
- npm install framer-motion(for framer  motion)

First, run the development server:
npm run dev

# Color Complexes 
- Background : 3F4F6 (neutral light gray)
- Buttons, Accents, CTAs : 
    - Primary Blue #2563EB (blue-600 Tailwind level)
    - Hover color #1D4ED8
    - Light variant (for subtle accents) #DBEAFE (blue-100)
- Heading:
    - #0F172A (slate-900) , Bold 600–700
    - Paragraphs: #475569 (slate-600), Border: #E2E8F0 (slate-200), active- #EFF6FF (blue-50)
    - Subtle labels / metadata: #64748B (slate-500)
- Gradient “Balloons / Blobs / Spheres”:
    - Use a Blue → Purple → Cyan gradient blend.
    - Best Ai Gradient: Mix of #2563EB → #7C3AED → #06B6D4

- Use the Tailwind slate scale — best for SaaS dashboards:

    Slate-900 → #0F172A

    Slate-800 → #1E293B

    Slate-700 → #334155

    Slate-600 → #475569

    Slate-500 → #64748B

    Slate-200 → #E2E8F0

    Slate-100 → #F1F5F9

    Slate-50 → #F8FAFC

    This gives your UI a structured, consistent feel.
